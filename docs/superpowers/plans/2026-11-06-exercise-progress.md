# 多题练习与本地进度实施计划

**目标**　学生可以切换三道练习，按题提交并复验，刷新后继续编辑。原平均值练习仍可通过旧接口运行。

**范围**　平均值、列表总和、列表元素个数共用现有受限执行器。浏览器按题保存草稿、最近五次提交摘要及曾通过状态。

1. `exercise.py` 添加 `sum`、`count` 两道题及用例。按题检查函数签名、判定结果并提供三级提示。运行执行器测试验证错误预置、修复和越界语法。
2. `app.py` 新增 `GET /api/exercises`，`POST /api/check` 支持可选 `exercise_id`。验证省略时沿用平均值练习，传错 ID 时返回可读错误。
3. `index.html` 添加题目选择与通过进度，切换题目时显示对应草稿和历史。浏览器验收覆盖失败、通过、切换和刷新恢复。
4. `README.md` 更新启动与演示步骤。运行 `python -B -m unittest discover -s tests -v` 复核。
