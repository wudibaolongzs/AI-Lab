# AI-Lab 首条原型实施计划

**目标**　从浏览器提交平均值函数，通过真实用例发现问题，查看逐级提示，修改代码后复验。

**依据**　《推荐参赛赛道》聊天的已定选题、第一周平均值示例，以及本轮对首条可运行原型的选择。

**边界**　Python 3.9+ 标准库，绑定本机回环地址。只支持一道题和受限语法。网页明确标识本地规则提示。提交内容留在本地进程，浏览器刷新清空当次记录。

1. `exercise.py` 解析函数并逐个计算样例。用测试验证错误样例、修复样例和越界语法。响应包含每个用例的实际值与预期值、诊断、三级提示。
2. `app.py` 通过 `GET /api/exercise` 提供题目，通过 `POST /api/check` 接收 `{"code":"..."}` 并返回评测结果。用 HTTP 测试检查页面、错误输入与复验。
3. `index.html` 提供编辑、提交、证据、提示和当前页面的提交记录。使用浏览器完成一次从预置错误到修复通过的操作。
4. `README.md` 记录启动方式、语法边界和 AgentArts 接入契约。用 `python -m unittest discover -s tests -v` 复核。
