# 云调用保护
使用 tools/start.py 启动时默认启用 AI_HINT_PROTECTION=1，可在本机 .env 显式设为0禁用，仅用于受控开发与评测。
直接运行 app.py 保留兼容行为，必须自行设置保护变量；共享部署必须启用。
## 当前固定策略
- 进程内所有用户和服务商共享并发2、滑动60秒最多6次新云调用。
- 合格提示缓存300秒，最多256条；缓存键以服务商、模型、地址、凭据、题号、失败证据与等级的摘要区分。
- 同键正在调用时立即使用本地busy回退，不重复请求；缓存命中有新request_id与原execution_id。
- 连续失败3次熔断30秒，到期只允许一个探测请求，无自动重试。
- 错误不缓存；题目范围含未知值时不调用云端。
- 保护只影响云提示，本地判题仍可使用。切换工作流版本后应重启服务清缓存。
## 限制与评测
进程重启会清空预算与缓存，多个进程不会共享限额。这不是账户级费用硬上限；仍须云平台侧设置额度告警。
全局限流会影响同班学生，需要真实身份后再加用户级配额。
72次配对评测必须使用专用的本机服务进程，明确设 AI_HINT_PROTECTION=0，停止其他用户访问，确认额度后采集；否则回退次数会反映限流和缓存影响，不能当作原始云端质量。
评测完成恢复为1并重启。采集报告注明保护开关和是否缓存命中，不混合不同设置。
