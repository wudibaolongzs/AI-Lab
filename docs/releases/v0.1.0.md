智学工坊 AI-Lab 首个公开版本，面向基础编程教学、团队协作与参赛演示，属于早期教学原型。

### 当前功能
- 28道本地教学题：受限Python解释器、测试证据、三级提示与修改复验。
- 统一题库：搜索、筛选、分页及JSON题包校验和事务导入。
- 学习记录：浏览器草稿、进度、记录导入导出、提示反馈与部分题目的理解验证。
- 课堂工作台：教师任务、学生求助、回复和班级权限隔离。
- 教师录题：粘贴文字、UTF-8 TXT、JPEG/PNG百度OCR适配；私有草稿经人工补齐、校验后导出，不自动发布。
- 洛谷精选300题元数据目录、Python/C++草稿及受控远程评测适配，默认关闭真实提交。
- AgentArts、腾讯云和DeepSeek提示适配，本地回退、调用保护及模拟联调工具。
- 深浅主题、手机布局、配置示例与部署指南。

### 验证
发布前本机回归：209项Python测试、27项Edge浏览器测试通过。
修正CI中Ubuntu最新镜像无法安装Python3.9的问题，Linux测试矩阵固定为Ubuntu22.04。

### 已知限制
- AgentArts、洛谷与百度OCR未完成本版本真实云端验收；模拟结果不代表真实服务或教学效果。
- 洛谷300条为元数据目录，不包含未获授权镜像的题面、样例或隐藏测试；不宣称已逐题双语言实测。
- 评测报告的人工质量评分尚未完成。
- 本地执行器支持白名单Python子集，不是通用Python执行环境；学习进度以浏览器本地保存为主。
- 教师录题首轮不解析Word/PDF，OCR结果与题包必须人工审核；公网使用仍需按部署指南配置HTTPS和访问控制。

### 启动
安装Python3.9或更新版本，在项目目录执行：
~~~powershell
python -B tools/start.py --port 8001
~~~
访问 http://127.0.0.1:8001 。无需云端凭据即可使用本地练习；配置说明见README及docs目录。许可证：MIT。
