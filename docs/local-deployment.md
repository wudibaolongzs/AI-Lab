# 启动和局域网演示

需要 Python 3.9+，运行时使用标准库。`requirements.txt` 标明当前无第三方运行依赖。

## 本机启动

在项目根目录复制 `.env.example` 为 `.env`，填入工作流调用地址和运行时 Key。也可留空，服务会使用本地提示。`.env` 按行使用 `变量名=值`，支持整行注释和成对引号，现有环境变量优先。启动器按文本读取配置。

```powershell
Copy-Item .env.example .env
python -B tools/start.py
```

首次复制后编辑 `.env`。已有 `.env` 时直接编辑原文件。启动脚本从任意工作目录运行均可定位项目配置，额外参数转交给服务。

## 同一 Wi-Fi 下的手机演示

用 `ipconfig` 找到电脑 Wi-Fi 网卡的 IPv4 地址，例如 `192.168.1.20`，替换下方示例。

```powershell
python -B tools/start.py --host 0.0.0.0 --port 8001 --allow-host 192.168.1.20
```

手机和电脑连接同一网络，在手机浏览器访问 `http://192.168.1.20:8001/`。需要允许电脑防火墙在所用网络接收该端口，路由器的客户端隔离也会影响访问。Host 白名单显式配置主机名或 IPv4，可重复传入 `--allow-host`，服务自动配上实际端口。填写白名单时只填写主机名或 IP。

当前服务提供局域网演示。公网发布仍需鉴权、HTTPS 终止和额度保护，相关工作单独验收。

## 测试和协作

```powershell
python -B tools/run_tests.py --offline
python -B tools/run_tests.py
```

离线模式显式跳过需要真实回环端口的测试，继续执行判题、流式响应契约、配置和评分检查。完整模式执行所有测试，网络权限失败会直接报告错误。CI 分别运行这两种模式。

Git 忽略本机 `.env`、编辑器缓存、Python 缓存和压缩包。历史报告继续保留供核对。开源许可证需由团队或学校确认权利归属后选择，当前交接只声明技术依赖。
