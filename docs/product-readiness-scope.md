# AI-Lab 成品范围与验收约定

核对日期：2026-11-07。此文件与后续建设计划配套使用。

## 建设目标

先形成可追溯、可复现的参赛作品，再支持 10–20 人的小范围试用，最后按真实需求考虑长期教学产品。当前团队以 2–3 人、编程基础为主；时间表是估算，按验收结果推进。

## 当前基础

三个列表练习；受限 AST 判题；三级本地提示；可配置的 AgentArts 调用与回退；浏览器草稿、进度与摘要记录；玻璃浅色/深色切换；启动器、Host 白名单、局域网参数；24 个评测样本及模拟工具。

## 产品边界

首阶段坚持现有 Python 标准库后端与网页，不做全面框架重写。云端只收失败证据和结构化诊断，学生源码保留本地。真实与模拟证据分开记录。公网试用前必须完成访问控制、HTTPS、额度保护与最小监控。任意 Python 执行、教师端、账号同步、MCP 都单独立项，不作为首轮参赛闭环的前置条件。

## 成品分级

1. 参赛版：真实调用可追溯、固定样本可复测、断网仍可完成练习、现场演示稳定。
2. 试用版：邀请用户安全访问、记录可恢复、费用与并发受控、问题有日志可查。
3. 教学产品：按试用反馈增加账户同步、教师教学流程和题库扩展，具备备份恢复与维护职责。

所有新增接口需保持旧判题契约兼容；所有权限以服务端校验为准；凭据不进入网页、Git、共享报告。没有真实数据时只写待验证，不写提升比例。
