# 百度拍照录题与教师资料辅助

## 当前范围
教师课堂工作台 /teacher 支持粘贴文字、读取本机 UTF-8 TXT，以及 JPEG/PNG 拍照或选图识别。Word/PDF、多页批量识别、数学公式与表格结构还原暂不支持。代码缩进、公式和测试期望值需人工核对；OCR不是自动出题或解题。

教师输入的原文、题包草稿只在本班可见，不进入公共题库。图片只用于本次百度请求，不保存到数据库；识别文字和百度log_id保留在本班草稿。来源及权利声明需人工确认，不代表系统已核查版权。

## 配置
先按 [课堂配置](classroom.md) 设置 AI_CLASSROOM_CONFIG 和 AI_CLASSROOM_DB。录题草稿和OCR次数存放在课堂SQLite数据库的独立表中，备份时需保护这些私有资料。

不配置百度也可完成文字录入、编辑、校验和导出。需要真实识别时：
1. 在百度智能云/AI开放平台创建文字识别应用，确认已开通“通用文字识别（高精度版）”，核对额度与计费。
2. 获取应用的 API Key、Secret Key。这是OCR应用凭据，与其他模型供应商的Key分开。
3. 在本机私有 .env 填写（不要提交Git或发到聊天）：
~~~dotenv
BAIDU_OCR_ENABLED=1
BAIDU_OCR_API_KEY=你的应用APIKey
BAIDU_OCR_SECRET_KEY=你的应用SecretKey
~~~
4. 重启 python -B tools/start.py --port 8001，打开 http://127.0.0.1:8001/teacher，使用教师凭证登录。
5. 先用不含个人信息的一张题目照片进行少量人工验证。上传前确认图片发送百度；失败不会自动重试，也不伪造识别文字。
6. 不使用云端时将 BAIDU_OCR_ENABLED 改回0并重启。

[官方鉴权说明](https://ai.baidu.com/ai-doc/REFERENCE/Ck3dwjhhu) · [高精度文字识别接口](https://ai.baidu.com/ai-doc/OCR/rkibizy1d)

## 录入到发布
1. 填写标题、原文/照片、来源，确认有权使用材料，创建待审核草稿。
2. 核对识别文字，编辑草稿。根据模板手动补齐本地题包：稳定题号、题面、来源许可、参数、返回类型、初始错误代码、参考实现、测试和三级提示。原材料不支持的答案不自动生成。
3. 保存后运行校验：使用现有受限解释器检查参考实现及预置错误，不能执行任意Python。
4. 完成人工审核确认，再导出JSON。校验成功只证明数据格式和既有测试通过，不代表教学质量或来源权利已经审核完成。
5. 维护者审阅后在服务器执行：
~~~powershell
python -B tools/question_bank.py validate 教师题包.json
python -B tools/question_bank.py preview 教师题包.json
python -B tools/question_bank.py import 教师题包.json
~~~
导出不会自动发布。发布前核对目标 AI_QUESTIONBANK_DB；重复题号由正式导入拒绝。发布后的题面会进入公共目录，参考答案仍属于服务端私有数据。

## 限制与保护
- 图片解码后最多2MiB，仅JPEG/PNG；Base64和URL编码过大时需先压缩。
- 资料接口JSON最多4MiB；原判题等接口保持12KiB。
- 原文最多20000字符，题包仍最多2MiB/200题。
- 教师专属权限与班级隔离；学生和未登录者不能录题或导出。
- OCR串行执行，繁忙返回429；本班每天UTC日最多20次识别尝试，失败也计数。计数写入数据库，重启不重置；不自动充值或重试。
- 密钥和Access Token只在后端，固定HTTPS端点，不跟随重定向。没有图片URL抓取。
- 未配置、超时、额度不足或响应无效时显示错误，仍可使用文字录入。

## 验收来源
本轮自动化验证使用模拟百度响应，不代表真实百度OCR质量与计费验收。配置应用后应手工记录：图片类型/大小（不存敏感图）、识别错漏、耗时、log_id、人工修订和题包校验结果。没有自动发起付费请求。
