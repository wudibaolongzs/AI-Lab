# 外部服务验收范围（P2）

本页统一洛谷与百度 OCR 的状态口径：**已收录**、**模拟通过**、**真实验证**三列必须分开写，不能互相替代。

| 服务 | 已收录 | 模拟/协议通过 | 真实验证 |
| --- | --- | --- | --- |
| 洛谷题目目录 | 300 个真实题号，九类数量与唯一性自动核对 | 本地模拟协议与幂等任务流程通过 | **0 次**真实试交 |
| 洛谷远程评测 | 双语言草稿、学生凭据、额度与任务持久化 | 模拟结果流程通过 | **未验收** |
| 百度 OCR | 高精度 OCR 适配器与人工录题草稿 | 模拟响应通过 | **0 次**真实识别 |

## 洛谷最小真实试交

前提：账号已授权、`LUOGU_ENABLED=1`、`LUOGU_PROTOCOL_VERIFIED=1`、`LUOGU_CONTENT_AUTHORIZED=1`，且学生凭据只放在本机。

1. 选 2 道代表题（一道简单、一道边界明显），各准备 3 份代码：正确、错误结果、编译失败（C++）。
2. 逐份提交，记录：题号、语言、代码版本、本地任务号、上游 requestId、状态、耗时、计费。
3. 同一份代码重复提交一次，确认幂等不产生第二条上游任务。
4. 核对页面显示“远程未开通/已提交/结果”与实际一致，且未将洛谷结果冒充本地判题。
5. 失败时保留原始错误码，不修改协议猜测重试；未经确认不做 300 题批量试交。

## 百度 OCR 最小真实识别

前提：`BAIDU_OCR_ENABLED=1`，API Key 与 Secret Key 只放操作员环境文件；上传前确认图片会发送百度。

1. 用一张不含个人信息的题目照片，人工记录图片类型与大小（不保存敏感原图）。
2. 触发一次识别，记录 `log_id`、耗时、识别文本与人工修订内容。
3. 将识别结果导入教师草稿，人工补齐题包并校验、导出；不自动发布到公共题库。
4. 失败时不自动重试，不伪造识别文字；记录错误码与计费状态。
5. 至少覆盖一种清晰照片与一种倾斜/低光照片，分别记录错漏。

## 结论口径

- 只写“目录已收录”时，不得暗示已能评测。
- 只写“模拟通过”时，不得写成“已接入真实平台”。
- 只有上表“真实验证”列填有日期、requestId/log_id、费用与失败案例，才可写“真实验证通过”。
- 两项服务都默认关闭；未配置时页面显示未开通或仅本地提示，这是预期行为。
