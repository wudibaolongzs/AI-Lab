# 手机浏览器验收（P1-2）

当前状态：移动视口自动化测试已通过（Edge 通道），**真实手机浏览器验证尚未执行**。

## 自动化覆盖

`tests/browser/mobile.spec.js` 在 390×844 视口运行 5 条：

1. 编辑代码并判题，页面不产生横向溢出，运行按钮仍在视口内。
2. 主题切换后刷新仍保持所选主题。
3. 草稿在刷新和切题后仍存在。
4. 提示展开后显示来源徽标，页面不横向溢出。
5. 视口高度压缩到 420（模拟软键盘弹出）后，运行与提示按钮仍可滚动到并可点击。

本地执行：

```bat
cd /d F:\GPT\华为ict
set PLAYWRIGHT_CHANNEL=msedge
npx playwright test tests/browser/mobile.spec.js
```

自动化只能证明 Chromium 内核在固定视口下的布局，不能证明 iOS Safari、Android 厂商浏览器、真实软键盘和触摸行为。

## 真机清单

准备两台设备：一台 iPhone（Safari）或 iPad，一台 Android（Chrome）。服务需在局域网可访问；启动时显式允许手机 IP：

```bat
cd /d F:\GPT\华为ict
python -B tools\start.py --port 8001 --host 0.0.0.0 --allow-host 192.168.1.50
```

把 `192.168.1.50` 换成手机访问时使用的电脑局域网地址，并在手机打开 `http://192.168.1.50:8001`。

## 记录与结论

- 记录手机型号、系统版本、浏览器版本、局域网地址、日期。
- 失败项附截图与复现步骤；不要只写“有点卡”。
- 只有两台真机的主要流程通过，才可写“手机真机已验证”。自动化通过只写“移动视口自动化通过”。

## 已知限制

- 本地服务只监听本机时手机无法访问；必须按 `docs/local-deployment.md` 显式设置 `--host` 与 `--allow-host`。
- 手机访问的是局域网 HTTP，不是公网 HTTPS；这与 [真实服务器部署验收](deployment-acceptance.md) 是两件事。
- 软键盘行为由操作系统决定，无法用 Playwright 精确复现。
