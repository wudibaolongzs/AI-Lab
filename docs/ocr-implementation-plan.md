# 教师资料与OCR实施记录
目标：教师受控上传照片或文字，形成待审核草稿，经本地题包校验和人工确认后导出。录入不直接发布。
1. 百度官方高精度OCR适配：固定HTTPS、显式开启、输入输出限制和离线契约测试。
2. 教师资料草稿：课堂鉴权与班级隔离、SQLite保存、持久化每日次数、校验与导出。
3. 教师页面：照片/粘贴/TXT、手动编辑、待审核状态和旧会话异步丢弃。
4. 集成与回归：原API请求限制保持、配置和代理上传上限配合、后端及浏览器回归。
设计决定：首轮支持JPEG/PNG/TXT和粘贴，不解析PDF/Word。测试和参考解由教师补齐，使用现有schema1导入维护流程。
证据：tests/test_baidu_ocr.py最初因适配器缺失失败；实现后5项通过。tests/test_material_http.py最初因路由缺失失败，接入后复验。
